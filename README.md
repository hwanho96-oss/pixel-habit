# Pixel Habit

판타지·픽셀 아트 세계관의 게이미피케이션 습관 트래커입니다. iOS와 Android를 동시에 지원합니다.

## 현재 구현

- 하단 5개 탭: 루틴, To do, 캘린더, 캐릭터, 종합
- **루틴 탭**: 퀘스트형 루틴 목록, 오늘 완료 체크, XP/레벨, 추가·삭제
- 나머지 탭은 이후 해금 예정인 플레이스홀더입니다.

## 실행

```bash
flutter pub get
flutter run
```

Android Studio에서는 이 폴더를 연 뒤 기기 또는 에뮬레이터를 선택하고 Run을 누르면 됩니다.
